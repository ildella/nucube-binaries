# nucube-binaries

Public binary mirror for [Nucube](https://nucube.music), a music player for
collectors. This repository carries the compiled linux payload
(`Nucube_<version>_x86_64.tar.gz` — binary, icons, desktop entry — plus its
`.sha256`) for package repositories that must download it anonymously, such
as Omarchy OPR (`pkgs.omarchy.org`).

The application source code is not published and is not contained here.
License: CC-BY-NC-ND-4.0 (see the license file installed by the package).

Payloads come from the Nucube release pipeline, stable tagged releases only
(`v<semver>`).
